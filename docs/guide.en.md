## Configure

1. Select **English** and your preferred theme. These preferences are saved automatically.
2. Enter the account token, with or without surrounding single/double quotes. It is masked by default. **Check account** only checks access; it does not send a message.
3. Add each channel ID separately. Channel/server names are resolved when added.
4. Enter up to 2,000 characters and optionally select a PNG, JPG, GIF or WEBP image up to 10 MB. GIF previews show the first frame; the original file is exported.
5. Set the interval from 1 to 10,080 minutes. Every round starts according to that interval; the first round starts immediately on runtime startup.

The runtime checks the last three messages, posts a typing indication and uses variable pauses. After a successful send it may remove its recorded previous message, only after confirming that message belongs to the same account. These behaviors are fixed in this version. Previous message IDs are stored in `ultimo_envio.json`.

## Local Windows execution

Click **Create BAT on Desktop**. The panel creates a desktop BAT and a folder containing its runtime, configuration and optional image. Keep the folder beside the launcher. No separate Python installation is needed on the computer running that generated package.

Open the desktop BAT to run. CMD displays timestamped logs and instructions: **press Ctrl+C or close the window to stop**. The computer must remain awake and connected. Closing the configuration panel does not stop a separately running BAT. Do not run multiple copies or both local and Discloud runtimes simultaneously.

## Discloud

Click **Create ZIP for Discloud**, save the file and upload it using your Discloud account. The ZIP contains `bot.py`, `core.py`, `i18n.py`, `config.json`, `requirements.txt`, `discloud.config`, an optional image and `README.txt` in English. Stop the hosted runtime from the Discloud dashboard.

Changing language in the panel affects packages generated or updated afterward. Existing packages keep their previous language until updated.

## Edit existing packages

Use **Load BAT or ZIP** and select a package generated by this application. Supported inputs are desktop launchers, internal `start.bat`/`iniciar.bat`, local ZIPs and Discloud ZIPs with compatible configuration. Imported BATs and code inside ZIPs are not executed. The panel reads only configuration and image data; it keeps a local image copy.

Edit the fields and click **Update loaded file**. A ZIP is replaced at the selected path. A BAT is kept at the selected path and points to a new runtime folder; the previous message state is carried forward. Stop the old console, then reopen the same BAT. For Discloud, upload the updated ZIP again; editing the ZIP does not redeploy it.

## Saved data and errors

Drafts and preferences are stored under `%APPDATA%\SelfBot Simple`. Draft credentials are protected with Windows DPAPI. Exported package credentials are not encrypted. The panel prompts to save, discard or cancel when closing with unsaved changes.

- **401:** credential rejected; verify it and the account.
- **403:** no permission or access to the channel.
- **404:** channel unavailable or missing.
- **429:** wait before retrying; the runtime respects the reported delay.
- **Invalid image:** choose another image or remove it.
- **Local executable missing:** run the build script before local export from source.

Do not paste tokens, generated packages or unredacted personal logs into public issues.

## Build

`scripts/build.py` first packages the console runtime, then embeds it and the source needed for Discloud export in the GUI executable. It uses the Python interpreter that runs the script. Output: `dist/SELF BOT DISCORD.exe` and a source-side `local-runner.exe` (both ignored by Git).
